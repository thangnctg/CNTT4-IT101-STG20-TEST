## 4.7. Báo cáo tổng hợp

### Các lệnh đã chạy

```bash
"=== TONG HOP LOG GAMEZONE ===" |
Select-String -Path logs/game.log -Pattern "WARNING" | ForEach-Object { $_.Line } | Add-Content -Path logs/tong_hop.txt
(Select-String -Path logs/game.log -Pattern "ERROR").Count | Add-Content -Path logs/tong_hop.txt
```

### Nội dung file logs/tong_hop.txt

```

# Noi dung file logs/tong_hop.txt sau khi tao:

[2026-03-30 10:20:45] WARNING: Slow query response time
```
