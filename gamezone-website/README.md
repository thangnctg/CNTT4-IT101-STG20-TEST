
# GameZone Website

*Dự án **trang web game** cơ bản được xây dựng nhằm mục đích giới thiệu và cung cấp thông tin các tựa game hot.*

## Thư mục dự án

| Thư mục / File | Mô tả nội dung |
| :--- | :--- |
| `docs` | Chứa tài liệu và các file cập nhật |
| `media` | Chứa hình ảnh, logo của dự án |
| `logs` | Chứa các file nhật ký hệ thống và báo cáo lỗi |

## Lệnh liệt kê nội dung

```powershell
Get-ChildItem -Recurse
```
## Danh sách công việc

-   [x] Hoàn thành cấu trúc thư mục dự án
    
-   [ ] Cấu hình file bảo mật
    

> **Lưu ý:** Tuyệt đối không upload file `.env` lên hệ thống quản lý mã nguồn để tránh lộ thông tin bảo mật.
